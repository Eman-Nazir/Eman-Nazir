## 🚀 Featured Project — VideoApp Backend

A production-level, YouTube-style platform backend, built and shipped day-by-day as the capstone of the 100-day challenge.

- **Stack:** Node.js, Express, MongoDB, Redis (Upstash), Stripe, Jest, Winston, deployed on Railway
- **Features:** Video CRUD with Cloudinary sync, role-based access control (user/creator/admin), comments, likes, subscriptions, OTP email verification, cron jobs, Stripe payments, Redis caching, MongoDB indexing, Swagger API docs
- **Testing:** 78 passing Jest tests
- **Auth:** JWT access/refresh tokens, bcrypt password hashing

🔗 **Live API:** https://videoapp-backend-production-a823.up.railway.app/api/v1
🔗 **API Docs:** https://videoapp-backend-production-a823.up.railway.app/api-docs
🔗 **Repository:** https://github.com/Eman-Nazir/videoapp-backend
